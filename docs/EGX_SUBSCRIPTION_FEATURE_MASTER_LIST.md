# Starta EGX Subscription Feature Master List

This document is written for end-user subscription packaging.
It is EGX-only, English-only, and removes internal product jargon.
Each item is phrased so it can be used directly in pricing pages, sales material, or subscription plan comparisons.

## Core EGX Market Access Features

- EGX market summary with daily market tone, advances vs declines, and overall session direction.
- Top gainers and top losers in the Egyptian Exchange, updated from live market data.
- Most active EGX stocks by trading volume.
- Sector performance overview across the Egyptian market.
- Single-stock live price lookup for any supported EGX company.
- Stock snapshot with current price, daily change, open, high, low, previous close, and volume.
- Market capitalization lookup for EGX-listed companies.
- EGX stock chart view with line and candlestick chart support.

## Core Stock Research Features

- Company profile for EGX-listed companies, including business overview and market classification.
- Latest stock news for a specific EGX company.
- Dividend history for EGX stocks.
- Dividend yield and payout-related insights for dividend-paying EGX companies.
- Ownership overview showing key shareholder information for supported stocks.
- Side-by-side comparison of 2 to 3 EGX stocks.
- Financial health check for a stock using balance sheet and profitability indicators.
- Fair value view for supported EGX stocks.
